# M6 Zero Lite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Zero Lite: the same workbench, served as a static site, opening a local folder via the File System Access API, with Nano completions and in-browser chat, and no daemon, terminal, LSP, graph, or git.

**Architecture:** One `packages/web` client. When the page URL has a session `token` (the `zero serve` link), keep today's WebSocket `RpcClient`. Otherwise show a landing screen, persist a directory handle, and wrap an in-process `SocketLike` (`localRpc`) around `BrowserFSWorkspace` + `LiteChatHost` so every existing panel still calls `client.request`. A new `session/hello` RPC returns `WorkspaceCapabilities`; the workbench hides subsystems whose flags are false.

**Tech Stack:** Bun, TypeScript strict ESM, Zod (protocol types only), React, File System Access API, IndexedDB, `ignore` (gitignore), Vite, Cloudflare Pages (`wrangler.toml` only, no CI job).

**Interfaces:**

- Produces:

  - `MemDir` / `createMemRoot(name: string): DirHandle` — in-memory handle tree implementing the subset `BrowserFSWorkspace` uses.
  - `class BrowserFSWorkspace` with:
    - `constructor(root: DirHandle)`
    - `read(path: string): Promise<string>`
    - `write(path: string, content: string): Promise<void>`
    - `tree(): Promise<TreeEntry[]>`
    - `create(path: string, kind: "file" | "dir"): Promise<void>`
    - `rename(path: string, newPath: string): Promise<void>`
    - `delete(path: string): Promise<void>`
    - `move(path: string, newPath: string): Promise<void>`
    - `copy(path: string, newPath: string): Promise<void>`
  - Local handle types (do not depend on DOM lib extras):

```ts
export interface FileHandle {
  name: string;
  kind: "file";
  getFile(): Promise<{ text(): Promise<string>; size: number }>;
  createWritable(): Promise<{ write(data: string): Promise<void>; close(): Promise<void> }>;
}
export interface DirHandle {
  name: string;
  kind: "directory";
  getDirectoryHandle(name: string, opts?: { create?: boolean }): Promise<DirHandle>;
  getFileHandle(name: string, opts?: { create?: boolean }): Promise<FileHandle>;
  removeEntry(name: string, opts?: { recursive?: boolean }): Promise<void>;
  entries(): AsyncIterableIterator<[string, DirHandle | FileHandle]>;
}
```

`tree()` always omits any entry whose path segment is `.git` or `node_modules` (any depth). Ignore-file parsing is Task 5.

`write` creates intermediate directories and replaces file contents. `create` fails if the path already exists. `rename`/`move` of a file is copy-bytes + `removeEntry` if there is no native rename.

- [ ] **Step 3: Implement `paths.ts`**

```ts
export function assertSafePath(path: string): string[] {
  if (path === "" || path === ".") return [];
  if (path.startsWith("/") || path.startsWith("\\")) throw new Error(`path escapes workspace: ${path}`);
  if (/^[A-Za-z]:/.test(path)) throw new Error(`path escapes workspace: ${path}`);
  const parts = path.split("/").filter((p) => p !== "");
  if (parts.some((p) => p === "." || p === "..")) throw new Error(`path escapes workspace: ${path}`);
  return parts;
}
```
